## 登录与获取 API 密钥

在[技元控制台][]登录后，点击左侧的“[API 密钥][]”，获取 API 密钥。

![API 密钥位置][]

点击“新建 API 密钥”，任意添加 API 密钥名称，分组选择 default（默认），点击“保存”即可。

![创建 API 密钥][]

密钥创建完毕后，可在列表中复制使用。

![API 密钥列表中的复制按钮][]

## 选择模型

前往[模型广场][]，查看目前拥有的模型。点击模型详情，可以查看价格，若模型有具体的调用文档，会在描述中列出。

![模型广场部分模型展示][]

![模型详情][]

使用 `POST /v1/images/edits` 编辑图片。接口基础地址为 `https://tokener.jeekmind.com`，请求体使用 JSON。

## 请求头

| 请求头 | 必填 | 说明 |
| --- | --- | --- |
| `Authorization` | 是 | `Bearer YOUR_API_KEY`，使用你的技元 API 密钥 |
| `Content-Type` | 是 | `application/json` |

## 请求字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `images` | object[] | 是 | 待编辑的图片列表，至少提供一张图片 |
| `images[].image_url` | string | 是 | 可访问的 HTTP(S) 图片 URL |
| `prompt` | string | 是 | 图片编辑要求 |
| `model` | string | 是 | 支持图片编辑的模型调用名，从 `/v1/models` 获取 |
| `size` | string | 否 | 输出图片尺寸，例如 `1024x1024`；支持的尺寸和默认值取决于所选模型 |

`images` 使用 OpenAI 兼容的 URL 引用结构，例如 `[{"image_url": "https://example.com/source.png"}]`。图片数量和格式限制取决于所选模型。

## 尺寸规则

以下模型支持使用 `WIDTHxHEIGHT` 字符串指定自定义分辨率，例如 `1536x864`：

- `gpt-image-2`
- `gpt-image-2-2026-04-21`
- `gpt-image-2.5-sunburst`
- `gpt-image-2.5-sunburst-2026-09-08`
- `gpt-image-2.5-flare`
- `gpt-image-2.5-flare-2026-09-08`

宽度和高度都必须能被 `16` 整除，宽高比必须在 `1:3` 至 `3:1` 之间。超过 `2560x1440` 的分辨率为实验性支持，最大支持分辨率为 `3840x2160`。请求尺寸还必须满足所选模型当前的总像素数及边长限制。

GPT Image 模型支持标准尺寸 `1024x1024`、`1536x1024` 和 `1024x1536`。支持自动尺寸的模型还接受 `auto`。

## 请求示例

将模型名和图片 URL 替换为实际值。

```bash
curl 'https://tokener.jeekmind.com/v1/images/edits' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "images": [{"image_url": "https://example.com/source.png"}],
    "prompt": "将背景改为清晨的湖面，保留主体外观",
    "model": "YOUR_IMAGE_MODEL",
    "size": "1024x1024"
  }'
```

## 返回结果

返回结构与[生成图片](/api-reference/images/generations)相同。将 `data[].b64_json` 解码为图片文件。

```json
{
  "created": 1795046400,
  "data": [
    {
      "b64_json": "BASE64_IMAGE_DATA"
    }
  ]
}
```

示例中的 Base64 为占位符。HTTP 错误请参考[错误处理](/api-reference/errors)。

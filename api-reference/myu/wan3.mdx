## 参数与素材规则

`model` 必填。你必须提供非空白 `prompt` 或至少一个素材。

`seconds` 默认 5 秒，支持整数 2–30 或 `-1`（智能时长）。分辨率支持 `480p`、`720p`、`1080p`，默认 `720p`。比例支持 `16:9`、`9:16`、`1:1`、`4:3`、`3:4` 和 `media_adaptive`；省略时由上游自适应。

普通参考最多 10 张图片、5 个视频、5 个音频。首帧和尾帧各最多 1 张，不能与普通参考素材混用。参考视频、音频各自合计不超过 15 秒，实际媒体时长由上游校验。

`options` 仅支持 `watermark` 和 `video_generation_seed`（整数 0–2147483647）。不支持文件、网页、Base64 或其它生成选项。

参考素材使用 `input_references` 对象数组，每项包含 `type` 和 HTTP(S) `url`，`role` 默认 `reference`。首尾帧仅用于图片。示例素材地址为占位符，调用前请替换。未知字段会被拒绝。

## 查询与下载

提交后，使用返回的 `id` [查询视频任务](/api-reference/videos/retrieve)。当 `status` 为 `completed` 时，推荐使用查询结果中的 `url_path` 下载视频；若为相对路径，先拼接 API 服务地址，并携带提交时的同一 API 密钥。

成功时返回 `url_path`；路径相对于 API 服务地址，下载需携带提交时的同一 API 密钥。此渠道仅提供主视频，不返回 `url_path_last_frame`。

响应字段及示例按生成中、成功、错误区分。`completed_at` 和下载字段仅在成功分支展示；成功时 `completed_at` 必填。错误原因在 `error.message` 中，没有错误原因时 `error` 为 `null`。`unknown` 表示暂时无法确定状态，可以继续查询。

渠道支持的全部模型见 [MYU 渠道](/channels/myu)。

`url` 已弃用，仅保留用于兼容，值与 `url_path` 相同。新客户端请使用 `url_path`。

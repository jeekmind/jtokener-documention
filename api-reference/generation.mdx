你可以按以下顺序调用接口：获取模型列表，选择模型并提交生成任务，使用任务 ID 查询结果和本次费用，并在任务完成后下载视频。

<Note>
  本页为接口文档草稿。模型列表和视频查询的返回示例已补充并脱敏。
</Note>

## 调用前准备

接口基础地址为 `https://tokener.jeekmind.com`。你可以参考[快速入门](/user-guide/start/quickstart)获取 API 密钥。

调用时，请替换示例中的占位符：

| 占位符 | 说明 |
| --- | --- |
| `YOUR_API_KEY` | 你的 API 密钥，放在 `Authorization: Bearer` 后面 |
| `YOUR_TASK_ID` | 提交生成任务后获得的任务 ID |

## 1. 模型列表

### 请求示例

```bash
curl --location 'https://tokener.jeekmind.com/v1/models' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```


### 请求头

| 请求头 | 说明 |
| --- | --- |
| `Authorization` | 格式为 `Bearer YOUR_API_KEY` |

### 返回示例

```json
{
  "data": [
    {
      "id": "gxc-doubao-seedance-2-5-260628",
      "object": "model",
      "created": 1626777600,
      "owned_by": "task plugin",
      "supported_endpoint_types": [
        "openai",
        "video-generation"
      ]
    },
    {
      "id": "jm-doubao-seedream-5-0",
      "object": "model",
      "created": 1626777600,
      "owned_by": "task plugin",
      "supported_endpoint_types": [
        "openai",
        "image-generation",
        "jeekmind-task"
      ]
    }
  ],
  "object": "list",
  "success": true
}
```

### 返回字段

| 字段 | 说明 |
| --- | --- |
| `success` | 示例中为 `true` |
| `object` | 列表对象，示例中为 `list` |
| `data` | 模型列表 |
| `data[].id` | 模型标识，提交任务时用作 `model` |
| `data[].object` | 对象类型，示例中为 `model` |
| `data[].created` | 模型创建时间戳 |
| `data[].owned_by` | 模型归属信息 |
| `data[].supported_endpoint_types` | 支持的接口类型标识；具体调用路径和参数请参考对应接口文档 |

## 2. 请求生成任务（图、视频）

### 视频生成

`POST /v1/videos`

以下示例使用 `gxc-doubao-seedance-2-5-260628` 模型，提交一段飞机在云层中穿行的视频生成任务。

```bash
curl --location --request POST 'https://tokener.jeekmind.com/v1/videos' \
  --header 'Content-Type: application/json' \
  --header 'Authorization: Bearer YOUR_API_KEY' \
  --data '{
    "model": "gxc-doubao-seedance-2-5-260628",
    "prompt": "飞机在云层中穿行",
    "seconds": 4,
    "resolution": "720P"
  }'
```

### 示例请求参数

| 参数 | 示例类型 | 示例值 | 说明 |
| --- | --- | --- | --- |
| `model` | string | `gxc-doubao-seedance-2-5-260628` | 必填，模型标识 |
| `prompt` | string | `飞机在云层中穿行` | 必填，描述你希望生成的内容，不能仅包含空白字符 |
| `seconds` | integer | `4` | 可选，视频时长，单位为秒；Seedance 2.5 支持 4–30 秒 |
| `resolution` | string | `720P` | 可选，Seedance 2.5 支持 `720P`、`1080P`，默认 `720P`，区分大小写 |

你可以使用 `input_references` 传入参考素材，通过 `options` 设置音频、水印和尾帧选项。完整参数和模型差异见 [GXC 概览](/api-reference/gxc/index)及 [Seedance 2.5](/api-reference/gxc/seedance25)。

## 3. 查询视频任务

`GET /v1/videos/{id}`

将 `YOUR_TASK_ID` 替换为提交视频任务返回的 `id`，使用同一 API 密钥查询任务状态和进度，并在任务完成后从响应的 `final_cost` 字段读取本次费用。完整参数说明见[查询视频任务](/api-reference/videos/retrieve)。

### 请求示例

```bash
curl --location --request GET 'https://tokener.jeekmind.com/v1/videos/YOUR_TASK_ID' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```

### 返回示例

以下为任务完成时的演示响应：

```json
{
  "id": "task_example",
  "object": "video",
  "model": "gxc-doubao-seedance-2-5-260628",
  "status": "completed",
  "progress": 100,
  "created_at": 1700000000,
  "completed_at": 1700000300,
  "final_cost": 1.4
}
```

### 返回字段

| 字段 | 说明 |
| --- | --- |
| `id` | 公开任务 ID，用于后续查询和下载 |
| `object` | 对象类型，固定为 `video` |
| `model` | 客户端请求的模型名称 |
| `status` | 任务状态：`queued`（排队中）、`in_progress`（进行中）、`completed`（已完成）、`failed`（失败）或 `unknown`（未知） |
| `progress` | 任务进度，整数类型 |
| `created_at` | 创建时间，Unix 秒级时间戳 |
| `completed_at` | 完成时间，Unix 秒级时间戳；任务未完成时可能省略 |
| `final_cost` | 本次任务的最终费用，单位为人民币元。示例中的 `1.4` 表示人民币 1.4 元 |

任务未完成时，可继续使用同一 `id` 查询。`status` 为 `completed` 后，通过 `GET /v1/videos/{id}/content` [下载视频](/api-reference/videos/content)。

你可以按以下顺序调用接口：获取模型列表，选择模型并提交生成任务，使用任务 ID 查询结果和本次费用，并在任务完成后下载视频。

<Note>
  本页为接口文档草稿。模型列表和视频查询的返回示例已补充并脱敏。
</Note>

## 调用前准备

接口基础地址为 `https://tokener.jeekmind.com`。你可以参考[快速入门](/user-guide/start/quickstart)获取 API 密钥。

调用时，请替换示例中的占位符：

| 占位符 | 说明 |
| --- | --- |
| `YOUR_API_KEY` | 你的 API 密钥，放在 `Authorization: Bearer` 后面 |
| `YOUR_TASK_ID` | 提交生成任务后获得的任务 ID |

## 1. 模型列表

### 请求示例

```bash
curl --location 'https://tokener.jeekmind.com/v1/models' \
  --header 'Authorization: Bearer YOUR_API_KEY'
```


### 请求头

| 请求头 | 说明 |
| --- | --- |
| `Authorization` | 格式为 `Bearer YOUR_API_KEY` |

### 返回字段

以下按视频任务状态列出字段，适用于 GXC、TYY、HC、MYU 和 ME 渠道。

<Tabs>
  <Tab title="生成中">

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 公开任务 ID，用于后续查询和下载 |
| `object` | string | 固定为 `video` |
| `model` | string | 客户端请求的模型名称 |
| `created_at` | integer | 创建时间，Unix 秒级时间戳 |
| `status` | string | `queued`（排队中）或 `in_progress`（生成中） |
| `progress` | integer | 当前生成进度 |
| `error` | null | 无错误时为 `null` |

  </Tab>
  <Tab title="成功">

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 公开任务 ID，用于后续查询和下载 |
| `object` | string | 固定为 `video` |
| `model` | string | 客户端请求的模型名称 |
| `created_at` | integer | 创建时间，Unix 秒级时间戳 |
| `status` | string | `completed` |
| `progress` | integer | 完成进度，示例为 `100` |
| `completed_at` | integer | 完成时间，Unix 秒级时间戳 |
| `error` | null | 固定为 `null` |
| `url` | string | 视频下载相对路径，拼接 API 服务地址后携带同一 API 密钥下载 |
| `url_last_frame` | string | 可选，仅 GXC、TYY 成功且有尾帧时返回；认证方式同视频下载 |

  </Tab>
  <Tab title="错误">

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 公开任务 ID，用于后续查询和下载 |
| `object` | string | 固定为 `video` |
| `model` | string | 客户端请求的模型名称 |
| `created_at` | integer | 创建时间，Unix 秒级时间戳 |
| `status` | string | `failed` |
| `progress` | integer | 失败时的进度，不代表生成成功 |
| `error` | object 或 null | 有失败原因时为对象，否则为 `null` |
| `error.message` | string | `error` 为对象时返回的失败原因 |

  </Tab>
</Tabs>

生成中和错误响应不返回 `url` 或 `url_last_frame`。`unknown` 表示状态未知，使用同一任务 ID 继续查询；有错误原因时可读取 `error.message`。

任务成功时，服务还可能返回 `final_cost`，表示本次任务的最终费用，单位为人民币元。

任务未完成时，可继续使用同一 `id` 查询。`status` 为 `completed` 后，通过 `GET /v1/videos/{id}/content` [下载视频](/api-reference/videos/content)。

使用 `POST /v1/videos` 提交 JSON 视频生成任务。`model` 和 `prompt` 为必填项，`prompt` 不能仅包含空白字符。

## 模型参数

| 模型 | 调用名 | 时长（整数秒） | 分辨率 | 图片 / 视频 / 音频数量上限 |
| --- | --- | --- | --- | --- |
| [Seedance 2.5](/api-reference/gxc/seedance25) | `gxc-doubao-seedance-2-5-260628` | 4–30 | `720p`、`1080p` | 30 / 10 / 10 |
| [Seedance 2.0](/api-reference/gxc/seedance20) | `gxc-doubao-seedance-2-0-260128` | 4–15 | `480p`、`720p`、`1080p`、`4K` | 9 / 3 / 3 |
| [Seedance 2.0 Fast](/api-reference/gxc/seedance20-fast) | `gxc-doubao-seedance-2-0-fast-260128` | 4–15 | `480p`、`720p` | 9 / 3 / 3 |

`seconds` 默认 5 秒，必须为整数。`resolution` 默认 `720p`，取值区分大小写。通过 `aspect_ratio` 指定画面比例，支持 `16:9`、`9:16`、`1:1`、`21:9`、`4:3` 和 `3:4`。

## 参考素材

使用 `input_references` 数组传入参考素材。每项必须包含 `type` 和 `url`：

| 字段 | 说明 |
| --- | --- |
| `type` | 媒体类型：`image`、`video` 或 `audio` |
| `url` | HTTP(S) URL，请确保在生成期间持续可访问 |
| `role` | 可选，默认 `reference`，当前仅支持此用途 |

素材数量按 `type` 分别统计，限制见上表。当前不支持首尾帧输入或 `aspect_ratio: "media_adaptive"`。

## 生成选项

在可选的 `options` 对象中设置以下布尔值：

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `return_last_frame` | `false` | 是否返回最后一帧 |
| `watermark` | `false` | 是否添加水印 |
| `generate_audio` | `true` | 是否生成音频 |

```json
{
  "model": "gxc-doubao-seedance-2-5-260628",
  "prompt": "参考图片中的纸船在清晨湖面上缓缓漂行",
  "seconds": 4,
  "resolution": "720p",
  "aspect_ratio": "16:9",
  "input_references": [
    {
      "type": "image",
      "url": "https://example.com/reference.jpg",
      "role": "reference"
    }
  ],
  "options": {
    "return_last_frame": false,
    "watermark": false,
    "generate_audio": true
  }
}
```

示例素材地址为占位符，调用前请替换为你的素材 URL。


## 查询结果与下载

使用提交时的同一 API 密钥查询和下载。查询响应始终包含 `error`，没有错误或任务成功时为 `null`；有失败原因时为 `{ "message": "失败原因" }`。

当 `status` 为 `completed` 时，响应包含 `url`。如果你设置 `options.return_last_frame: true` 且模型返回尾帧，响应还包含 `url_last_frame`。任务未成功或没有尾帧时，不返回对应下载路径。

这两个字段均为相对路径。将路径拼接到你的 API 服务地址后，携带 `Authorization: Bearer YOUR_API_KEY` 下载。

```json
{
  "id": "video_example",
  "object": "video",
  "model": "gxc-doubao-seedance-2-5-260628",
  "status": "completed",
  "progress": 100,
  "created_at": 1793851200,
  "completed_at": 1793851260,
  "error": null,
  "url": "/v1/videos/video_example/content",
  "url_last_frame": "/v1/tasks/video_example/artifacts/last_frame/content"
}
```

```bash
# 下载视频
curl 'https://tokener.jeekmind.com/v1/videos/video_example/content' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -o video.mp4

# 下载尾帧（仅在返回 url_last_frame 时可用）
curl 'https://tokener.jeekmind.com/v1/tasks/video_example/artifacts/last_frame/content' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -o last-frame.jpg
```

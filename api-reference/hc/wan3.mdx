## 参数与素材规则

`model` 必填。你必须提供非空白 `prompt` 或至少一个素材；提示词最长 20000 字符。

`seconds` 默认 5 秒。有参考视频时支持 1–30 秒，无参考视频时支持 2–30 秒，也可传 `-1` 使用智能时长。分辨率支持 `480p`、`720p`、`1080p`，默认 `720p`。比例默认 `media_adaptive`。

普通参考最多 10 张图片、5 个视频、5 个音频。首帧和尾帧各最多 1 张，不能与普通参考素材混用。只接受 HTTP(S) 素材 URL，不支持文件或网页输入。

`options` 支持 `watermark`（默认 `false`）、`generate_audio`（默认 `true`）、`optimize_prompt`（默认 `true`）和 `video_generation_seed`（`-1` 或 0–2147483647）。不支持 `return_last_frame`。

上游业务异常或无法识别的任务状态可能显示为 `unknown`，请继续查询确认。

参考素材使用 `input_references` 对象数组，每项包含 `type` 和 HTTP(S) `url`，`role` 默认 `reference`。首尾帧仅用于图片。示例素材地址为占位符，调用前请替换。未知字段会被拒绝。

## 查询与下载

提交后，使用返回的 `id` [查询视频任务](/api-reference/videos/retrieve)，完成后[下载视频](/api-reference/videos/content)。

成功时返回 `url`；路径相对于 API 服务地址，下载需携带提交时的同一 API 密钥。此渠道仅提供主视频，不返回 `url_last_frame`。

响应字段及示例按生成中、成功、错误区分。`completed_at` 和下载字段仅在成功分支展示；成功时 `completed_at` 必填。错误原因在 `error.message` 中，没有错误原因时 `error` 为 `null`。`unknown` 表示暂时无法确定状态，可以继续查询。

渠道支持的全部模型见 [HC 渠道](/channels/hc)。

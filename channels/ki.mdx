| [Ki Magi-2](/api-reference/ki/magi-2) | `ki-magi-2` |

## 调用流程

1. 使用 `POST /v1/videos` 提交 JSON 任务。
2. 保存返回的 `id`，通过 `GET /v1/videos/{id}` 查询。
3. 当 `status` 为 `completed` 时，使用查询结果中的 `url_path` 下载视频。先拼接 API 服务地址，再携带提交时的同一 API 密钥请求。

接口基础地址为 `https://tokener.jeekmind.com`。密钥获取方式见[快速入门](/user-guide/start/quickstart)。

同一个模型支持文生视频、首尾帧和参考媒体三种模式，根据 `input_references` 自动选择。只提供主视频产物。成功响应使用 `url_path` 返回下载路径，同时保留值相同的已弃用兼容字段 `url`。新客户端请使用 `url_path`。
